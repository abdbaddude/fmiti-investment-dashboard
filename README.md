# FMITI Investment Conversion Dashboard

Projects Nigeria pipeline pilot ($78.5bn · 65 projects) for FMITI / NIPC.

## Live

Open `index.html` or deploy this folder to Netlify / Vercel as a static site.

## Data

- `projects.json` – full structured pipeline with bankability, bottlenecks, conversion probability
- `projects.csv` – flat export for Excel / analysis

## PWA

Installable progressive web app (manifest + service worker).
